## Дополнительные требования

Дополнительные требования, которые я принял, для упрощения реализации

1. Один пользователь может пройти опрос один раз.
2. Позволяем отвечать на один и тот же вопрос. Каждый ответ сохраняем. Не перезаписываем.
3. Ожидаем, что пользователь не будет отвечать на будущие вопросы, которые идут за тикущим вопросом. Даже если ответить, нечего не сломается - ответит еще раз.
4. Ожидаю, что администратор не будет менять порядок вопросов опроса, который уже пользователи проходят.
5. Опросы сторого линейны и не могут менять порядок вопросов в зависимости от ответов пользователя.

## Краевые случае

Следующие краевые случаи были покрыты и протестированны в ручную:
- Предоставление ответа, который отстуствует в списке ответов вопроса
- Ответ на предыдущий вопрос.
- Ответ на будущий вопрос.
